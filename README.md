# photoresistor_basic_3LEDs
This program includes a photo-resistor.
When the room light is shining on the photo-resistor, the voltage is around 175 so the yellow LED turns on. When the torch light from my watch is shone onto the photo-resistor, the voltage is around 270, so the green LED turns on. When I use my hand to cover the photo-resistor, the voltage is around 37, so the white LED turns on.
The voltage changes because when the light is low, there is low conductivity and high resistance in the photo-resistor. Because the resistance is high, the overall current in the circuit decreases so the voltage decreases.
